# 65 — ADMIN OPERATIONS CONTRACT

## User operations
Search, inspect permitted profile metadata, suspend/restore, role/capability management, support actions.

## Content operations
Draft/review/publish/unpublish/version, source/provenance inspection.

## Tool operations
Engine version, health, latency, failures, jobs, feature flags.

## Moderation
Queue, case, evidence, action, audit.

## Destructive actions
Require explicit confirmation, reason and audit. Where possible use reversible state instead of hard delete.
