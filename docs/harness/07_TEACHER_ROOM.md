# 07 — TEACHER ROOM / SCHOOL ENGINE

## Professor title
É um capability paid/future entitlement. Ao possuir a capacidade, o usuário pode criar uma Room. O mesmo usuário permanece aluno/músico.

## Room screens
Room Overview; About; Curriculum; Course; Module; Lesson; Assignments; Submissions; Members; Community; Calendar; Events/Live; Materials; Progress; Settings; Moderation; Analytics.

## Teacher workspace
Dashboard operacional com alunos, cursos, pendências, calendário, submissions, eventos, materiais e saúde da Room.

## Classroom chat
Chat de turma é contextual à Room/course/class, não mensageria privada entre usuários. Deve ter moderação, retenção e permissões.

## School
Uma escola pode agrupar Rooms e professores. A primeira versão pode tratar Room como unidade principal e preparar o domínio para School.

## Professor profile
O Profile exibe a Room vinculada: descrição, cursos, aulas recentes, lives, projetos, comunidade e indicadores escolhidos pelo professor.
