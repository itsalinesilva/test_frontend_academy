# 58 — SCORE SCREEN CONTRACTS

## New Score
Title, composer/creator metadata, instruments, staff count, clef, key/time signature.

## Editor
Palette/input method; staff canvas; selection; inspector; playback; history; save status.

## Note entry
Click/touch/keyboard/MIDI. Correct duration, rests, accidentals, ties, voices and measure validation.

## Playback
Start/stop/pause; tempo; loop; cursor; part selection. Playback follows score model, not screenshot rendering.

## Practice
Attach exercise target; follow cursor; capture timing/accuracy where supported.

## Import/export
Format support is declared explicitly. Unsupported features produce warnings rather than silent loss.
