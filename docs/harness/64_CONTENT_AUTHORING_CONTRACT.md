# 64 — CONTENT AUTHORING CONTRACT

## Lesson schema
metadata, objectives, skills, prerequisites, sections, media, activities, assessment, sourceRefs, audienceVariants.

## Activity schema
activityType, prompt, inputs, scoringPolicy, feedbackPolicy, skillRefs, difficulty, provenance.

## Source refs
Each factual unit can point to one or more sources. Store exact edition/section/page only where legally and technically appropriate.

## Review workflow
Draft → source review → pedagogical review → technical validation → moderation → publish → version.

## Kids
Audience variant references canonical content ID; does not fork the curriculum silently.
