# 11 — VERTICAL SLICES A–G

A — Identity: signup → role selection → profile → home.
B — Academy: catalog → course → lesson → exercise → result → profile.
C — Practice: path → skill builder → simulator → telemetry → evidence.
D — Worlds: work/composer/era → tour → passport → badge.
E — Studio: create project → record/edit → save version → portfolio.
F — Community: post → topic → reply → report → moderation → profile.
G — Teacher: upgrade/capability → create Room → course → lesson → student enrollment → submission → event.

Each slice must be executable by a real user and include persistence, authorization, error states, analytics, tests and accessibility.
