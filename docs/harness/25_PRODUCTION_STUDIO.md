# 25 — PRODUCTION STUDIO

## Scope
A serious music production environment, not a mock DAW.

## Workspace
Project browser; timeline; tracks; transport; audio editor; MIDI/piano roll; instrument browser; mixer; routing; effects; automation; asset browser; takes; versioning; export.

## Audio
Record, monitor, import, waveform, split, trim, move, fades, gain, normalize when appropriate, non-destructive edits, buses, inserts, sends, meters, render.

## MIDI
Note editing, velocity, timing, quantization, controller data, routing and playback.

## Synth Generator
A practical entry point for singers, learners and producers: generate a playable/digital accompaniment, synth instrument or backing context. It can support users without a physical instrument. It must not imply physical instrument mastery.

## AI generation
Generation is an optional production layer. User must know when material is AI-generated. Rights/provenance metadata must be preserved. Avoid claiming ownership or originality automatically.

## Mobile
Mobile is a production companion: record, review, arrange, basic edit, capture, project sync and share. Desktop remains the deep editing environment where necessary.
