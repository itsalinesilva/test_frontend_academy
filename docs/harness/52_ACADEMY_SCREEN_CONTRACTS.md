# 52 — ACADEMY SCREEN CONTRACTS

## Academy Home
Regions: global context, continue learning, recommended learning, active paths, recent activity, catalog entry. Recommendation must derive from real progress/goal data; no fabricated personalization.

## Catalog
Search, filters, category, instrument, level, duration, skill, world, availability. Result must identify content type and status.

## Course Detail
Header; outcomes; skills; prerequisites; curriculum; instructor/source; progress; enrollment; certificate criteria; discussion. Mobile keeps primary action accessible.

## Lesson Reader
Header; lesson content; media; activity; notes/materials; progress; previous/next. Save progress at stable checkpoints.

## Activity
Render activity from schema. Capture attempt. Do not embed answer/scoring rules solely in client.

## Assessment
Attempt count; score; feedback; remediation; retry. For engine-scored activities, display confidence/limitations.

## History
Chronological and derived views. Content version is retained with completion record.
