# 23 — PRACTICE / SKILL BUILDER

## Two entry points
1. Inside an Academy instrument/path lesson.
2. Central Skill Builder.

Both use the same Exercise and Attempt domain.

## Practice flow
Choose skill → choose instrument/voice → choose level/method/preset → calibrate → practice → feedback → retry → result → save → evidence.

## Presets
Example: Violin / Suzuki Level 1 / skill = intonation. Other methods may include Hans Sitt, Maia Bang and platform-authored progression where permitted.

Preset metadata must identify source/method, level, exercise ID, target skills and scoring policy.

## Telemetry
Instrument input, note events, pitch, timing, string/fret/fingering where detectable, score position, mistakes, repetitions, duration. Store only what is necessary.

## Recording
Audio/video/MIDI/simulator telemetry can be synchronized by server session timeline.

## Replay
User can inspect recording, score cursor, detected notes, timing and feedback. Replay is an evidence product, not merely a media player.
