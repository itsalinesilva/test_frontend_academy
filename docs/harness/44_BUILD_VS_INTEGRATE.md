# 44 — BUILD VS INTEGRATE

## BUILD
Differentiation: unified identity/progression; Music Graph; evidence; skill telemetry integration; curriculum-to-practice bridge; Room-to-profile bridge; cross-tool workflows; product UX.

## INTEGRATE
Commodity infrastructure and mature engines when license permits: OAuth, database, object storage, notation rendering, audio DSP, MIDI, waveform rendering, codecs, search, analytics infrastructure.

## ADAPT
Open-source music tools whose UI/architecture can be wrapped. Maintain adapter and provenance/license record.

## REJECT/REPLACE
Libraries with incompatible licenses, abandoned security posture, poor performance, unmaintainable APIs or output quality below the product contract.

The goal is not to rewrite the world; it is to own the orchestration, UX, data model, quality and differentiated integration.
