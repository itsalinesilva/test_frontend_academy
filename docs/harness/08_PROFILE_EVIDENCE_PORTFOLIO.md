# 08 — EVIDENCE / PORTFOLIO

Evidence é a ponte entre “fiz algo” e “posso demonstrar algo”.

## Evidence sources
Course, assessment, exercise, practice, simulator, score, recording, performance, project, composition, room assignment, event, challenge, teaching activity.

## Artifact types
Audio, video, score, MIDI, project package, image, PDF/document, external URL.

## Portfolio
Título, contexto, objetivo, papel do usuário, skills, instrumentos, work references, process notes, result, evidence, visibility, version.

## Credential issuance
Rules engine verifica prerequisites, assessment, evidence, reviewer status quando necessário. Emitir immutable credential record + verifiable ID.

## Profile display
Academic, Practice, Studio, Rooms, Worlds, Community. Usuário escolhe o que expor.
