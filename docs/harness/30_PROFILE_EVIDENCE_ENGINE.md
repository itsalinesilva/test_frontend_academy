# 30 — PROFILE / EVIDENCE ENGINE

## Event-driven updates
`course.completed` can update Academic history and credential eligibility. `practice.completed` can update Practice history and skill score. `project.published` can update Portfolio and Community if chosen.

## Portfolio evidence
An item stores evidence references rather than duplicating media.

## Public profile
Server builds a visibility-filtered projection. Never send private fields to frontend and rely on CSS to hide them.

## Resume/CV view
Academic achievements, instruments, competencies, credentials, selected portfolio and external links. It is a musical/professional CV, not a social feed clone.
