# 69 — MOBILE NATIVE CONTRACT

Mobile is a first-class client, not a scaled webpage.

## Must support
Auth, profile, Academy consumption, Skill Builder, practice capture, tuner/metronome, score viewing/practice, community, Rooms, notifications and project review/capture.

## Deep tools
Desktop/web may expose deeper Studio/Score editing. Mobile must still preserve access to project state and not create a dead-end.

## Offline
Explicit cache/sync states. Secure local storage for credentials. LocalStorage-like web storage must never be used for secrets.
