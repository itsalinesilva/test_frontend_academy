# 29 — COMMUNITY ENGINE

## Units
Feed, Post, Topic, Forum, Group, Connection, Event, Room community.

## Post types
Text, link, audio, video, image, artifact reference, practice result, project, score, achievement.

## Context
Posts may attach to Work, Composer, Course, Skill, Instrument, Room, Event or Project.

## No DM
No private direct messaging. Room class chat is scoped to the class/room.

## Moderation
Report → queue → review → action → appeal if defined → audit.

## Child safety
Child accounts default to restricted visibility and stronger moderation. Public participation must be explicitly designed and compliant.
