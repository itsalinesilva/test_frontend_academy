# MASTER BLUEPRINT — v3

## Product equation
ACADEMY + WORLDS + COMMUNITY + STUDIO LAB + PRODUCTION STUDIO + ROOMS + PROFILE.

## Reference architecture blend
Coursera-like Academy gives formal learning structure. Duolingo-like Practice gives short feedback loops and mastery progression. Skool-like Rooms give teachers their own operational communities/courses. LinkedIn-like Profile gives professional identity, CV, evidence and connections. Professional music software gives category depth.

## Differentiation
The product is not differentiated because it contains a tuner that already exists. It is differentiated because a learner can discover a concept, study it, practice it with the correct instrument/method preset, receive measurable feedback, record the attempt, turn it into evidence, expose it on a professional profile, discuss it in a forum, use the skill in a studio project, and later teach it in a Room—all without leaving the ecosystem.

## Core lifecycle
Knowledge → Course → Exercise → Skill → Practice → Measurement → Evidence → Credential → Profile → Community → Creation → Teaching → new Knowledge.

## Product quality rule
Breadth is allowed; shallowness is not. When a tool is introduced, implement the minimum coherent category workflow first, then expand to professional depth. Never market a prototype as a complete professional tool.

## Implementation rule
Build the orchestration and contracts in Node/TypeScript. Integrate specialized open-source/Python engines behind adapters. The UI should be prepared before engine replacement so the product does not need a rewrite when a higher-quality engine is introduced.
