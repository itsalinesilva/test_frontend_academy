# 47 — ACCESSIBILITY

Target WCAG 2.2 AA where applicable. Keyboard navigation, visible focus, semantic labels, screen-reader support, reduced motion, sufficient contrast, captions/transcripts, accessible media controls and error messaging.

Score and timeline tools need keyboard shortcuts plus accessible alternative controls.

Kids needs large targets and clear language, not merely larger font.

Audio-dependent exercises must have appropriate non-audio alternatives when the learning objective permits.
