# 51 — ONBOARDING SCREEN CONTRACT

## Flow
Splash → Auth → Account type → Profile basics → Instruments/interests → Learning goals → Privacy → Home.

## Account type
Options: Aluno, Músico, Professor, Criança. Explain that title does not block other experiences. Professor capability requires its future entitlement; Músico capability controls full production access; Aluno is default/free; Criança activates guardian flow.

## Profile basics
Name, avatar source, headline, bio, instruments, skill interests, external links and visibility. Google avatar is the default when provided; user can change according to product policy.

## Completion
Onboarding is resumable. Partial completion persists. No forced public profile.

## Kids
Guardian must be established before child public/social capabilities. Copy is simplified; knowledge depth is unchanged.

## Tests
Duplicate account; OAuth callback; invalid email; role tampering; refresh mid-flow; offline resume; guardian link; admin seed; visibility defaults.
