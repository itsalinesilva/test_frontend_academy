# 26 — VOICE / EAR / TUNER

## Tuner
Chromatic baseline plus instrument-aware modes, calibration, reference pitch, visualization, history and practice linkage.

## Metronome/Drone
Tempo, subdivisions, accents, tap tempo, count-in, presets and practice recording linkage.

## Voice
Range discovery, pitch exercises, timing, breath exercises, recording, playback, pitch contour, karaoke.

## Karaoke
Song/score/audio context, lyrics only where licensed/owned, transport, key/tempo controls where available, vocal monitoring, pitch feedback when configured.

## Ear
Intervals, scales, chords, rhythm, melody, timbre. Every exercise has target, attempt, result, feedback and progression mapping.

## Audio analysis
Python engine can provide pitch/onset/segment metrics. Always expose confidence/limitations where detection can fail.
