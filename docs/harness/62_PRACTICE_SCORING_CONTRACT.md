# 62 — PRACTICE SCORING CONTRACT

## Principles
Score only what the engine can measure reliably. Every metric has definition, range, tolerance and confidence.

## Examples
Pitch accuracy; onset timing error; rhythm deviation; note coverage; repetition count; consistency; completion.

## Result
Raw measurements are retained privately according to policy; user-facing result is normalized and explainable.

## No fake precision
Do not display “98.73% accuracy” if the detector confidence is low. Use ranges or confidence indicators.

## Academic mapping
Result → Skill assessment → progress update → evidence eligibility.
