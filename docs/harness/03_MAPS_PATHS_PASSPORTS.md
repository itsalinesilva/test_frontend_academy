# 03 — MAPS / PATHS / PASSPORTS

## Três mapas de trajetória
Aluno: aprender e dominar competências. Professor: aprender a ensinar e operar Rooms. Músico: prática, criação, repertório e produção.

Os mapas coexistem. “Ascensão” significa aquisição de nova capacidade/título, não bloqueio de outros caminhos.

## Estrutura
World → Map → Path → Track → Course/Module → Skill → Activity → Evidence → Credential.

## Passports
Passport é uma coleção narrativa de progressos. Pode representar instrumento, período, competência, exploração ou trajetória profissional.

## Credenciais
Badge = conquista discreta. Microcredential = competência delimitada demonstrada. Credential = conjunto formal de competências. Certificate = registro de conclusão. Rank = posição contextual.

## Score
O score não deve ser um número mágico. Deve possuir componentes explicáveis, por exemplo: completion, proficiency, consistency, accuracy, repertoire, evidence e community contribution, cada um com escopo próprio.

## Rankings
Nunca ordenar “quem é melhor músico” globalmente. Ranking por desafio, curso, instrumento, faixa etária quando apropriado, Room ou temporada, com privacidade e proteção infantil.

## World tour
Contexto → compositor → obra → escuta → partitura → técnica → prática → performance → criação → evidência.
