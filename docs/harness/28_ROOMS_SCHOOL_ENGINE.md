# 28 — ROOMS / SCHOOL ENGINE

## Skool-like functional model
Room combines course content + community + calendar/events + members + teacher controls.

## Create Room flow
Professor capability → Create Room → identity → audience/privacy → curriculum → community settings → publish → invite/enroll → manage.

## Student flow
Discover → join/enroll → consume lesson → perform assignment → submit evidence → discuss → attend event → progress.

## Teacher flow
Create → teach → moderate → assess → publish → review analytics → improve curriculum.

## Live
Event object; scheduled state; live state; recording state; replay. Provider can be integrated later; architecture must not hardcode a vendor.
