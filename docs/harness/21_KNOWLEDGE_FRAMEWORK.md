# 21 — KNOWLEDGE FRAMEWORK

## Source-first model
Knowledge unit is represented independently of its UI expression.

`Concept → Definition → Explanation → Example → Media → Exercise → Assessment → Skill → Source references`.

## Source hierarchy
1. Licensed/acquired reference books and courses.
2. Public-domain/reference data.
3. APIs/datasets under compatible licenses.
4. Authored synthesis and pedagogical expression.

## Initial reference corpus
Bohumil Med theory + exercises; Grout/Palisca history; University of Edinburgh course materials supplied by owner; three Berklee books supplied; Suzuki, Hans Sitt and Maia Bang method references as licensing/provenance permits.

## Authoring pipeline
Ingest metadata → rights check → extract allowed facts/notes → create concept map → author lesson → author examples → create exercises → link source → review → publish.

## No silent plagiarism
Do not paraphrase protected chapters at exhaustive granularity. Do not reproduce exercise books wholesale. Create original exercises that test the same learning objective when rights do not permit reproduction.

## Kids transformation
`canonical_content_id` remains identical; `audience_variant=kids` stores simplified explanation, examples and UI copy. Formal knowledge is preserved.
