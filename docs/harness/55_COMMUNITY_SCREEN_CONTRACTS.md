# 55 — COMMUNITY SCREEN CONTRACTS

## Feed
Sources: connections, followed forums, Rooms, events, challenges and opted-in public activity. Ranking must be explainable and safe.

## Forum Directory
Categories by instrument, theory, history, production, repertoire, method, course and community.

## Topic
Title, body, context tags, replies, moderation controls, report. Support score/work/course references.

## Create Post
Text/link/audio/video/artifact. Validate media and visibility. Draft/autosave where applicable.

## Event
Overview, host, schedule, eligibility, registration, live/replay state, discussion.

## Moderation
Reported item state is visible to reporter where policy allows; actions are audited.
