# 56 — ROOM SCREEN CONTRACTS

## Public Room
Identity, teacher, purpose, curriculum, sample content, community, upcoming events, join/enroll.

## Student Room
Course progress, lessons, assignments, submissions, discussions, calendar, events, class chat.

## Teacher Room
Operational dashboard, curriculum editor, materials, assignments, submissions, members, events, chat moderation, analytics, settings.

## Create Room
Name → description → visibility → audience → structure → curriculum → community → rules → publish.

## Classroom chat
Threaded/contextual, moderated, tied to Room/class; not a global DM system.
