# 21.1 — CATÁLOGO DE APIs DE CONTEÚDO & CAMADA DE RESOLUÇÃO DE ENTIDADES

**Status:** Normativo · complementa `21_OPEN_SOURCE_API_CATALOG.md`
**Origem:** ADR-001.C (ver `CLAUDE_STATE.md §8`)
**Última verificação empírica:** 2026-09-16
**Escopo:** O doc 21 governa **dependências de código** (bibliotecas). Este documento governa **fontes de conteúdo** (obras, partituras, gravações, manuscritos, metadados) e a camada que as unifica.

---

## 1. PRINCÍPIO

A plataforma **não hospeda acervo próprio de obras**. Ela **resolve, referencia e reproduz** conteúdo de domínio público a partir de fontes públicas canônicas, e **gera** o que puder ser gerado programaticamente.

Três regras invioláveis:

1. **Nenhuma obra entra no produto sem proveniência resolvida.** Toda obra exibida carrega, no mínimo, um identificador canônico externo e a base sobre a qual o domínio público foi determinado.
2. **Domínio público é calculado, nunca presumido.** Ver §5.
3. **Nenhum dado de fonte externa é tratado como verdade local.** Toda resposta externa é normalizada para o domínio da plataforma antes de tocar a UI.

---

## 2. CORREÇÃO FORMAL — A API DO IMSLP

> ⚠️ **Retificação de auditoria.** O `CLAUDE_AUDIT.md` e a primeira redação do ADR-001.C afirmaram que *"o IMSLP não possui API oficial; é apenas a API do MediaWiki"*. **Isso está incorreto.**

O IMSLP publica uma API própria e documentada:

```
https://imslp.org/imslpscripts/API.ISCR.php
    ?account=worklist
    /disclaimer=accepted
    /sort=id
    /type=2          # 1 = compositores (people), 2 = obras (works)
    /start=0
    /limit=<n>
    /retformat=json
```

**Verificado em 2026-09-16:**

| Aspecto | Resultado |
| :--- | :--- |
| Resposta | `HTTP/1.1 200 OK` · JSON válido |
| `Content-Type` | `text/plain; charset=UTF-8` — **declara texto, entrega JSON**; o cliente deve fazer `JSON.parse` explícito e nunca confiar no content-type |
| Formato | Objeto indexado por posição (`{"0":{...},"1":{...}}`), **não** um array — exige normalização |
| Campos úteis | `id`, `type`, `parent` (categoria do compositor), `intvals.composer`, `intvals.worktitle` |
| Parâmetro obrigatório | `disclaimer=accepted` — sem ele a requisição é recusada |
| **CORS** | 🔴 **Ausente.** Verificado explicitamente: zero cabeçalhos `Access-Control-Allow-Origin`, inclusive com `&origin=*` |

**Consequências arquiteturais:**
- A sintaxe de parâmetros é **posicional separada por `/`**, não `&` — um cliente HTTP convencional montado com `URLSearchParams` produz uma URL inválida. Exige construtor de URL dedicado.
- A ausência de CORS **obriga** o proxy via Cloudflare Pages Function (§6). Não é uma otimização; é requisito de funcionamento.
- A API do MediaWiki (`imslp.org/api.php`) permanece útil como fonte **secundária** para conteúdo de página e listagem de arquivos, mas também não tem CORS.

## 3. CATÁLOGO DE FONTES

### 3.1 Aprovadas — acesso direto do navegador

| Fonte | Endpoint | CORS | Licença dos dados | Papel |
| :--- | :--- | :---: | :--- | :--- |
| **Wikidata** | `wikidata.org/w/api.php` + `query.wikidata.org/sparql` | ✅ `*` (com `&origin=*`) | CC0 | **Hub de resolução de entidades** (§4) |
| **MusicBrainz** | `musicbrainz.org/ws/2/` | ✅ `*` | Dados CC0 · esquema CC-BY-NC-SA | Identidade de obra, gravação, autoria, relações |
| **Wikimedia Commons** | `commons.wikimedia.org/w/api.php` | ✅ `*` (com `&origin=*`) | Domínio público / CC por arquivo | Manuscritos, fac-símiles, gravuras, retratos |
| **Internet Archive** | `archive.org/advancedsearch.php` | ✅ `*` | Varia por item — **verificar item a item** | Gravações históricas em domínio público |
| **Open Opus** | `api.openopus.org` | ✅ `*` | Domínio público | Catálogo de compositores e obras, curado e leve |

### 3.2 Aprovadas — exigem proxy

| Fonte | Motivo | Papel |
| :--- | :--- | :--- |
| **IMSLP / Petrucci** | Sem CORS (§2) | **Partituras em domínio público** — fonte primária de notação |
| **Musica Brasilis** | Site HTML, sem API pública detectada | Repertório brasileiro — exige *scraping* respeitoso ou curadoria manual com cache |

### 3.3 Recusadas

| Fonte | Motivo da recusa |
| :--- | :--- |
| **MuseScore.com** | Acervo majoritariamente **enviado por usuários e protegido por direito autoral**, não domínio público. Sem API aberta para este uso. Tratar apenas como **alvo de formato** (MusicXML/MSCZ), nunca como fonte de conteúdo. |
| Qualquer agregador sem licença verificável por item | Viola a regra 1 do §1. |

## 4. CAMADA DE RESOLUÇÃO DE ENTIDADES

### 4.1 O problema

A mesma obra existe sob identidades incompatíveis:

```
IMSLP        "6_Violin_Sonatas_and_Partitas,_BWV_1001-1006_(Bach,_Johann_Sebastian)"
MusicBrainz  4a8c18a0-efe2-4b56-a127-9958dec08ad3
Wikidata     Q<id>
Open Opus    id numérico interno
Plataforma   "bwv-1001"   ← hoje, hardcoded em WorldsAtlasScreen.tsx
```

Sem uma camada de reconciliação, cada tela inventa a sua chave — que é exatamente o defeito `K-05` catalogado na auditoria.

### 4.2 A solução — **Wikidata como hub**

Wikidata carrega referências cruzadas para todas as demais fontes. Uma única consulta SPARQL resolve a identidade completa de uma obra.

**Propriedades verificadas empiricamente em 2026-09-16:**

| Propriedade | Significado | Verificado |
| :--- | :--- | :--- |
| `P86` | compositor | ✅ |
| `P839` | **ID do IMSLP** (título de página ou categoria) | ✅ |
| `P435` | **ID de obra no MusicBrainz** (UUID) | ✅ |
| `P434` | ID de artista no MusicBrainz | ✅ |
| `P373` | categoria no Wikimedia Commons | ✅ |
| `P18` | imagem (URL direta via `Special:FilePath`) | ✅ |
| `P569` / `P570` | nascimento / **morte** — base do cálculo de domínio público (§5) | ✅ |

**Consulta de referência (executada e validada):**

```sparql
SELECT ?w ?wLabel ?imslp ?mb WHERE {
  ?w wdt:P86 wd:Q1339 ;      # compositor = J.S. Bach
     wdt:P839 ?imslp .        # tem ID no IMSLP
  OPTIONAL { ?w wdt:P435 ?mb }
  SERVICE wikibase:label { bd:serviceParam wikibase:language "pt,en" }
}
```

Retorno real obtido:

```
Sonatas e Partitas para violino solo
  IMSLP = 6_Violin_Sonatas_and_Partitas,_BWV_1001-1006_(Bach,_Johann_Sebastian)
  MB    = 4a8c18a0-efe2-4b56-a127-9958dec08ad3
```

Rótulo em **pt-BR** disponível — a plataforma não precisa traduzir títulos à mão.

### 4.3 Contrato do domínio

```ts
/** Identidade canônica de uma obra, reconciliada entre fontes externas. */
export interface CanonicalWorkIdentity {
  /** Chave interna estável e legível. Ex.: 'bach-bwv-1001'. */
  readonly localId: EntityId;

  /** Hub de reconciliação. Ausente ⇒ obra não resolvida. */
  readonly wikidataId?: `Q${number}`;

  readonly externalRefs: {
    readonly imslpPage?: string;        // P839
    readonly musicbrainzWorkId?: string; // P435 (UUID)
    readonly openOpusWorkId?: string;
    readonly commonsCategory?: string;   // P373
  };

  readonly title: LocalizedText;         // pt-BR do rótulo Wikidata, com fallback en
  readonly composer: CanonicalPersonIdentity;

  readonly publicDomain: PublicDomainAssessment; // §5
  readonly resolution: ResolutionMetadata;
}

export interface ResolutionMetadata {
  /** Como a identidade foi obtida. Nunca 'ASSUMED'. */
  readonly method: 'WIKIDATA_SPARQL' | 'MUSICBRAINZ_LOOKUP' | 'MANUAL_CURATION';
  readonly resolvedAt: IsoDateTime;
  /** Concordância entre fontes. < 1 exige revisão humana antes de publicar. */
  readonly confidence: number;
  readonly conflicts?: readonly string[];
}
```

### 4.4 Pipeline

```
   consulta do usuário / seed de curadoria
                  ↓
        [1] Wikidata SPARQL  ──→  Q-id + P839 + P435 + P373 + rótulo pt-BR
                  ↓
        [2] enriquecimento paralelo
              ├─ IMSLP  (via proxy)      → arquivos de partitura + licença declarada
              ├─ MusicBrainz             → gravações, autoria, relações
              ├─ Commons (P373/P18)      → manuscritos, gravuras, retratos
              └─ Internet Archive        → áudio histórico
                  ↓
        [3] cálculo de domínio público (§5)
                  ↓
        [4] normalização → CanonicalWorkIdentity
                  ↓
        [5] cache local (localStorage, TTL por fonte)
                  ↓
                  UI
```

**Invariante:** a UI **nunca** fala com uma fonte externa diretamente. Ela consome apenas `CanonicalWorkIdentity` já resolvida. Isso mantém a arquitetura de portas e adaptadores já estabelecida em `adapters/engines/`.

## 5. DETERMINAÇÃO DE DOMÍNIO PÚBLICO

Domínio público é **calculado a partir da data de morte do autor (Wikidata `P570`)**, nunca presumido pelo fato de a obra ser antiga ou de estar num acervo público.

```ts
export interface PublicDomainAssessment {
  readonly status: 'PUBLIC_DOMAIN' | 'LIKELY_PUBLIC_DOMAIN' | 'UNDETERMINED' | 'PROTECTED';
  readonly basis: 'AUTHOR_DEATH_PLUS_TERM' | 'SOURCE_DECLARED_LICENSE' | 'MANUAL_REVIEW';
  readonly authorDeathYear?: number;
  /** Jurisdição do cálculo. Brasil: vida + 70 anos (Lei 9.610/98, art. 41). */
  readonly jurisdiction: 'BR' | 'US' | 'EU';
  readonly assessedAt: IsoDateTime;
  readonly note?: string;
}
```

**Regras:**
- `status === 'PROTECTED'` ou `'UNDETERMINED'` ⇒ **a obra não é exibida nem reproduzida.** Pode aparecer apenas como referência bibliográfica textual.
- A **edição** de uma partitura tem direito autoral próprio, independente da obra. Uma obra de Bach em domínio público pode ter uma edição de 1990 protegida. A licença declarada pelo IMSLP para **cada arquivo** prevalece sobre o cálculo de vida+70 da obra.
- Internet Archive: licença **por item**. Nunca assumir domínio público pelo fato de estar no Archive.

## 6. PROXY E CACHE — CLOUDFLARE PAGES FUNCTION

Uma única Function atende os dois casos sem CORS, respeitando a decisão "sem banco de dados":

```
/functions/api/sources/[source]/[[path]].ts
```

**Responsabilidades:**
1. Encaminhar para IMSLP e Musica Brasilis, adicionando cabeçalhos CORS na resposta.
2. Montar a URL posicional do IMSLP (`/chave=valor/`) corretamente (§2).
3. `JSON.parse` explícito da resposta `text/plain` do IMSLP.
4. Normalizar o objeto indexado do IMSLP para array.
5. Aplicar `User-Agent` identificado — exigido pela etiqueta do MusicBrainz e recomendado no Wikimedia.
6. Cache de borda via `caches.default`, com TTL por fonte.
7. Rate limiting de saída (§7).

**Restrição:** a Function é **stateless**. Não guarda conteúdo. Cache é apenas cache de borda, descartável. Nenhum dado de usuário passa por ela.

## 7. LIMITES DE USO E ETIQUETA

| Fonte | Limite verificado / documentado | Obrigação |
| :--- | :--- | :--- |
| **MusicBrainz** | Cabeçalhos `X-RateLimit-Limit: 400`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` observados na resposta | **User-Agent identificável obrigatório** (aplicação + contato). ~1 req/s anônimo. Respeitar `X-RateLimit-Reset`. Tratar `503`/"server is currently busy" com *backoff* — ocorreu durante a verificação |
| **Wikidata SPARQL** | Timeout de consulta; uso intenso é limitado | User-Agent identificável. Consultas enxutas, sempre com `LIMIT`. Preferir `wbgetentities` a SPARQL quando o Q-id já for conhecido |
| **Wikimedia Commons** | Limite generoso | User-Agent identificável. `&origin=*` obrigatório para CORS |
| **IMSLP** | Não documentado publicamente | Uso conservador, cache agressivo, `disclaimer=accepted` |
| **Internet Archive** | Limite generoso | Verificar licença por item |
| **Open Opus** | Sem registro exigido | — |

**Governança:** toda chamada externa passa por um adaptador com *timeout*, *retry* com *backoff* exponencial e **degradação graciosa** — falha de fonte externa nunca derruba a tela; produz estado vazio explicável.

## 8. MÍDIA GERADA PELA PLATAFORMA

O que **não** vem de fonte externa é gerado programaticamente — determinístico, gratuito e academicamente honesto:

| Artefato | Geração |
| :--- | :--- |
| Pautas, claves, armaduras, exemplos notacionais | SVG programático (biblioteca de notação a definir no doc 21) |
| Diagramas didáticos — ciclo das quintas, teclado, braço, cifras, condução de vozes | SVG programático |
| Áudio de exemplo, intervalos, escalas, acordes, playback de partitura | Síntese WebAudio (base já presente em `infrastructure/audio/synth.ts`) |
| Áudio do usuário | MP3 importado, decodificado **localmente** via `decodeAudioData`; nunca enviado a servidor |

🔴 **Vedado:** gerar por IA "manuscritos históricos", "gravuras de época" ou "fac-símiles". Destrói a proveniência que a Constituição §2 exige e cria material historicamente falso num produto acadêmico. Manuscrito real vem do Wikimedia Commons ou do IMSLP, com proveniência — ou não é exibido.

---

## 9. CRITÉRIOS DE ACEITE

Uma integração de fonte de conteúdo só é considerada pronta quando:

1. Existe adaptador tipado, isolado, com *timeout*, *retry* e degradação graciosa.
2. Toda entidade exibida possui `CanonicalWorkIdentity` com `resolution.method ≠ 'ASSUMED'`.
3. `PublicDomainAssessment` está calculado e registrado; `PROTECTED`/`UNDETERMINED` não renderiza mídia.
4. `User-Agent` identificável em toda requisição de saída.
5. Limites de uso respeitados e testados contra resposta `503`.
6. Cache com TTL definido por fonte.
7. Testes cobrindo: resposta bem-sucedida, fonte fora do ar, resposta malformada, conflito de resolução entre fontes.
8. Nenhum identificador de obra hardcoded em componente `.tsx`.
